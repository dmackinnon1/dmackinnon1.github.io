# Redirects for the old kixote pages

The tour puzzles used to be published at `dmackinnon1.github.io/kixote/`. These pages
forward each old address to its new home under `dmackinnon1.github.io/chessdom/`, so
existing links (for example from blog posts) keep working.

To use them, replace the contents of the `kixote/` folder in the `dmackinnon1.github.io`
repository with the `.html` files in this folder.

If the chessdom folder on the site is ever renamed, change `../chessdom/` in each file.
